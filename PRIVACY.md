# Privacy

MoL Keyboard is offline by default. It does not require an account and does not
include analytics, advertising, telemetry, or remote tracking. It does not
upload recordings, keystrokes, device identifiers, or children's data.

Optional network control features will bind to the local machine by default and
will require explicit user activation. Platform operating systems and user-added
services may have their own privacy practices outside MoL Keyboard's control.

# 隐私

MoL Keyboard 默认完全离线，不要求账号，不包含分析、广告、遥测或远程追踪，也不会上传
录音、按键、设备标识或儿童数据。

可选网络控制功能默认只绑定本机，并需用户明确启用。平台操作系统以及用户自行添加的服务
可能有其自身隐私规则，不受 MoL Keyboard 控制。
