## More or Less Zhang's Keyboard / 张多少的键盘

MoL Keyboard is a local-first digital instrument built around one portable C11
engine. “MoL” means More or Less: the same musical object can be a command-line
tool, a background service, a browser instrument, a mobile application, or a
small ESP32 device without becoming several incompatible products.

MoL Keyboard（More or Less Zhang's Keyboard，张多少的键盘）是一件以单一可移植
C11 引擎为核心的本地优先数字乐器。同一个音乐对象可以是命令行工具、后台服务、浏览器
乐器、移动应用或 ESP32 小设备，而不是彼此不兼容的多套产品。

## Candidate features / 候选功能

- One caller-memory C ABI for Native, WebAssembly, and ESP-IDF; deterministic
  frame scheduling and no allocation, blocking, logging, or managed callback in
  the render path. / 同一调用方内存 C ABI 覆盖 Native、Wasm 与 ESP-IDF，渲染路径无
  分配、阻塞、日志或跨语言回调。
- A 30-key C4–F6 instrument with octave, transpose, eight scales, ten chord
  modes, sustain, pitch bend, portamento, metronome, exact transport, and six
  arpeggiator modes. / 30 键 C4–F6 乐器，含八度、移调、八种音阶、十种和弦、延音、
  弯音、滑音、节拍器、精确 transport 与六种琶音模式。
- Eighteen data-driven procedural instruments across six synthesis models,
  with Chorus, Delay, Reverb, DC blocking, smoothing, and limiting. / 18 个数据
  驱动过程音色、六类合成模型以及 Chorus、Delay、Reverb、直流阻断、平滑和限幅。
- Bounded recording/playback, Mol Sequence v1, strict JSON and MIDI conversion,
  editing, and deterministic PCM16/PCM24/float32 WAV rendering. / 有界录音回放、
  Mol Sequence v1、严格 JSON/MIDI 转换、编辑及确定性多格式 WAV 渲染。
- Static and shared C SDKs with an explicit 47-symbol export surface and ABI
  compatibility baseline, plus a physical-capture latency analyzer. / 静态与动态
  C SDK 具有明确的 47 符号导出边界和 ABI 兼容基线，并提供物理采集延迟分析器。
- Headless desktop daemon/CLI, offline PWA, native mobile audio hosts, and
  target-accurate ESP32/ESP32-S3 firmware capabilities. / 无界面桌面服务与 CLI、
  离线 PWA、原生移动音频宿主及按芯片事实区分的 ESP32 固件能力。
- Local-only defaults, private recording storage, no analytics or advertising,
  exact dependency locks, preserved notices, and SPDX SBOM. / 默认仅限本机、私有
  录音存储、无分析或广告、依赖精确锁定、完整 notices 与 SPDX SBOM。
