# Known Limitations

The repository is at M0. It does not yet produce audio or ship any user-facing
runtime, service, application, firmware, or package. Platform entries are plans,
not support claims.

The current Windows host has Visual Studio 2026 and CMake 4.4.0, but Ninja is not
on the default `PATH`. Emscripten and ESP-IDF are not installed. Hardware,
background-audio, latency, underrun, and device-routing claims therefore remain
unverified.
